Room panes, the pick-history list, lobby lists, creation stages, Green Room content, commissioner workspaces and in-room ceremony lineups use their natural height. Desktop workspaces, portaled composers/settings dialogs and the standalone projector retain their existing viewport boundaries. The private live player screen uses the same reading pattern inside its existing focus trap: clock, tabs and picks share one keyboard-accessible **Live draft content** region below its persistent back controls.

Pick-log and team-card actions occupy a separate row so they cannot squeeze the artwork or title away. The history fade is limited to its desktop scrolling list. View changes reset the actual mobile vertical owner while preserving horizontal board position. Existing desktop player-screen offsets, fullscreen ownership, wake-lock release, audio and focus restoration remain unchanged.
