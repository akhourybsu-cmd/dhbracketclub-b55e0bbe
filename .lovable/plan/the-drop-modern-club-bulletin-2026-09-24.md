# The Drop — Modern Club Bulletin

## Goal
Transform the existing Daily Find experience into **The Drop**: a premium daily collection where each member leaves one meaningful artifact for the club.

## What will change
- Rename all visible Daily Find labels, prompts, sharing copy, menu entries, and onboarding language to **The Drop** while preserving existing data and links.
- Rebuild the main screen around a crisp editorial header, **Add Today’s Drop** action, today’s collection, streak, filters, and archive access.
- Give every Drop a collectible anatomy: type tab, date stamp, title/content treatment, media or article preview, social actions, and “Dropped by…” attribution.
- Differentiate **Learned**, **Read**, and **Saw** with restrained amber, blue, and coral accents and type-specific layouts.
- Upgrade the calendar into a memory map with photo previews, category indicators, a clear streak summary, and a polished selected-day collection.
- Restyle the composer and detail view so adding a Drop feels like placing an artifact into the archive.
- Keep reactions, comments, chat sharing, search, links, photos, permissions, and the one-per-day rule unchanged.

## Motion and accessibility
- Add subtle card entry, tap lift, reaction pop, archive transitions, and a short “drop into place” completion motion.
- Respect reduced-motion preferences and retain readable contrast and 44px touch targets in light and dark modes.

## Technical notes
- Add scoped semantic tokens for The Drop in the global theme so both light and dark modes remain consistent.
- Reuse the existing data model, routes, upload flow, article previews, and club asset gate; no database changes.
- Verify the mobile layout, desktop layout, both themes, link previews, composer, calendar, and navigation labels.
